## ✨ About The Project

**Aesthetic by Nikhil** is a personal artist portfolio website designed to showcase my portrait drawings and creative artwork in a visually appealing and immersive way.

The website focuses on combining **art, creativity, modern UI design, animations, and responsive development** to create an engaging experience across mobile phones, tablets, laptops, and desktop screens.

The project also demonstrates my skills in **frontend development, responsive design, UI/UX, and modern web technologies**.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd Aesthetic-By-Nikhil
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

The terminal will provide the local development URL, usually:

```text
http://localhost:5173
```
